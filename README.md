# Itzfizz Scroll-Driven Hero

React and Vite implementation of a scroll-driven Itzfizz hero animation.

## Stack

- React and Vite
- GSAP and ScrollTrigger
- Tailwind CSS utilities
- Custom CSS for visual styling

## Scripts

```bash
npm install
npm run dev
npm run lint
npm run build
```

Animation logic lives in `src/hooks/useHeroAnimation.js`. Hero presentation is split into focused components under `src/components`.
